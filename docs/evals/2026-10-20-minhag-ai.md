# Eval: the community setting in AI answers (2026-10-20)

**What changed.** The settings menu now has a community choice: Sephardi (the default), Mizrahi (Edot HaMizrach) or Ashkenazi. The AI follows it. The prompt now:

- gives the halacha source order for that community;
- asks the answer to say which community's custom it follows;
- for Sephardi and Mizrahi readers who get English answers, asks for Sephardi transliteration.

Ashkenazi readers keep their own forms.

**The script.** `scripts/eval_minhag_ai.py`. It is local only: it uses the keys in `.env`, which it never prints, and it sets `SENTRY_DSN=""` so a run never alerts the error channel.

## Method

The eval asks four English questions under each lens the site sends (12 answers):

1. Can I make a bris on Shabbat if the eighth day falls then?
2. What do we eat in the sukkah on the first night of Sukkot?
3. Is it customary to stay up all night on Shavuot?
4. What blessing do I say before eating rice?

The lenses are:

| Lens | Who it's for |
|---|---|
| `Sefardic` | Sephardi readers |
| `Iraqi` | Mizrahi readers. It maps to the existing Iraqi/Baghdadi lens, the tradition of the Ben Ish Chai and the Kaf HaChaim. |
| `Ashkenaz` | Ashkenazi readers |

The questions go through `backend.claude.ask_claude`, the real models, with gemini-3.5-flash-lite as the primary. The first question deliberately uses the Ashkenazi form "bris".

Each answer gets two checks:

- **Ashkenazi forms:** `backend.minhag.ashkenazi_forms` matches these whole words, ignoring case: Shabbos, Shabbes, Sukkos, Succos, Shavuos, Bais, emes, Toras, bris.
- **Names the community:** the answer mentions Sephardi, Mizrahi, Edot, Iraqi, Baghdad or Ashkenaz.

## Results

| | Sefardic | Iraqi | Ashkenaz |
|---|---|---|---|
| Answers with Ashkenazi forms | 0/4 | 0/4 | 0/4 |
| Answers naming the community | 4/4 | 4/4 | 4/4 |

What the answers looked like:

- **Transliteration.** The Sefardic and Iraqi answers wrote "brit"/"berit" even though the question said "bris". They also used "Shabbat", "Sukkot" and "Shavuot".
- **Sources.** The Iraqi answers cited the Ben Ish Chai in all four questions. The Sefardic answers cited the Shulchan Aruch and, where relevant, the Kaf HaChaim. The Ashkenaz answers cited the Mishnah Berurah on the Shavuot and blessing questions.
- **Ashkenazi lens.** The Ashkenaz answers still used Sephardi spellings. That is allowed: the instruction only stops Sephardi and Mizrahi answers from using Ashkenazi forms. It never forces Ashkenazi forms.

## Limits

- This is one run of 12 answers on the primary model only. The Claude fallback path was not exercised.
- There is no before/after baseline. The old prompt was not run on the same questions.
- The community check is a keyword match. It shows the answer names a community, not that it names the right one. The cited authorities above were checked by hand.
- Yalkut Yosef is not on Sefaria. It appears only in the AI's source order, never in the reader's library lists.

## Re-run

```bash
SENTRY_DSN= .venv/bin/python scripts/eval_minhag_ai.py --save
```

The script exits 1 when any Sephardi or Mizrahi answer uses an Ashkenazi form.
